# Phase 6: Block/Floor/Room System

## Built
- Block selector connected to map state.
- Floor selector filtered by selected block.
- Room list filtered by block and floor.
- Room details panel with block, floor, type, accessibility, and access status.
- Local location search across room number, room name, and room type.
- Search result click selects the correct block, floor, and room.
- 3D scene now filters visible floors by selected block/floor state.

## Boundary
Navigation buttons are present as product UI hooks, but real route calculation remains Phase 7.
