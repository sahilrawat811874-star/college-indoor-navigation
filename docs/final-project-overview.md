# Final Project Overview

This project is a production-oriented 3D College Indoor Mapping & Navigation System built through 13 phases.

## Capabilities
- 3D campus map with block/floor/room selection.
- Search by room, lab, department, and facility.
- A* indoor routing over navigation nodes and edges.
- Accessibility-aware route mode.
- Natural-language smart search.
- Admin map management foundation.
- JWT/RBAC backend security.
- PostgreSQL/PostGIS spatial database foundation.
- Docker and cloud deployment preparation.

## Current Demo Scope
The system ships with replaceable demo data for A Block, B Block, and C Block. Real deployment requires replacing demo coordinates, rooms, corridors, stairs, elevators, and facilities with actual college data.
