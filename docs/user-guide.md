# User Guide

## Find a Room
Use the search bar to search for a room number, lab, department, or facility.

Examples:
- `A-204`
- `BCA Lab`
- `Library`

## Navigate
1. Select your current location.
2. Select or search for a destination.
3. Click Navigate.
4. Follow the route line and instructions.

## Accessibility Mode
Enable wheelchair-accessible routing to avoid stairs and inaccessible paths where data is available.

## 2D/3D View
Use the 2D/3D toggle to switch between top-down and interactive 3D views.
