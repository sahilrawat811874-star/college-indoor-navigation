# Cloud Hosting Options

## Recommended for first real deployment
- Vercel frontend
- Render backend
- Supabase PostgreSQL with PostGIS

This is the fastest reliable setup for a college project evolving into production.

## Recommended for scalable institutional deployment
- AWS CloudFront + S3 frontend
- ECS Fargate backend
- RDS PostgreSQL/PostGIS
- ElastiCache Redis
- S3 for assets
- CloudWatch and Sentry for monitoring
